# Changelog

All notable changes to OpenCode Multiuser should be documented here.

The project follows [Semantic Versioning](https://semver.org/): `MAJOR.MINOR.PATCH`.

## 6.8.0

Centralized Semantic Versioning baseline continuing the existing v6.x release lineage.

This version consolidates the previously developed multi-user OpenCode platform features, including rootless Podman workspace isolation, systemd/Quadlet lifecycle management, Traefik gateway routing, persistent workspaces, idle cleanup, OIDC/local authentication, administrator user management, and the enterprise portal UI.
