    scripts/reset-orphans.sh

    4 lines, 0 of 0 definitions explained, 2 line notes. View original

    In the guide: Installation, versioning and releases

    Cleanup helper that force-removes leftover OpenCode workspace containers from Podman. The name filter is strict on purpose, so only dynamically allocated workspace containers are touched and fixed services such as PostgreSQL and Traefik are not.

    1#!/usr/bin/env bash
    2set -euo pipefail
    3# Removes only dynamically allocated OpenCode workspace containers.
    Line 3

    States the safety contract: only dynamically allocated workspace containers are removed.

    4podman ps -a --format '{{.Names}}' | awk '/^oc-[0-9]+-[a-f0-9]+$/' | xargs -r podman rm -f
    Line 4

    Lists all containers, running or stopped, by name. awk keeps only names matching ^oc-<digits>-<hex>$, which is the shape the comment calls dynamically allocated. The kept names are passed to podman rm -f, which stops and removes them. xargs -r skips podman rm when nothing matched, so the script is a no-op on a clean host. Container names that do not fit the pattern are never selected.
