    In the guide: Installation, versioning and releases

    Builds a release archive opencode-multiuser-<version>.zip plus a .sha256 checksum file from the repository tree. The version is read from scripts/version.py show, and the archive is staged with rsync (excluding .git, virtualenvs, caches and build output) before being zipped.

    1#!/usr/bin/env bash
    2set -euo pipefail
    3​
    4ROOT=$(cd "$(dirname "$0")/.." && pwd)
    5PYTHON_BIN=${PYTHON_BIN:-python3}
    6VERSION=$($PYTHON_BIN "$ROOT/scripts/version.py" show)
    7NAME="opencode-multiuser-${VERSION}"
    8DIST_DIR=${1:-"$ROOT/dist"}
    Lines 4–8

    Resolves the repository root from the script location, so it works from any current directory. PYTHON_BIN can be overridden, and the first argument sets the output directory (default <root>/dist). The version is obtained by running version.py show, which keeps one source of truth for the number.

    9STAGE=$(mktemp -d)
    10trap 'rm -rf "$STAGE"' EXIT
    Lines 9–10

    Stages the copy in a temporary directory that the EXIT trap deletes, even if a later step fails.

    11​
    12command -v rsync >/dev/null 2>&1 || { echo "ERROR: rsync is required" >&2; exit 1; }
    13command -v zip >/dev/null 2>&1 || { echo "ERROR: zip is required" >&2; exit 1; }
    Lines 12–13

    Checks that rsync and zip exist before doing any work and exits with a clear error if not.

    14​
    15mkdir -p "$DIST_DIR" "$STAGE/$NAME"
    16rsync -a \
    17 --exclude '.git' \
    18 --exclude '.venv' \
    19 --exclude '.pytest_cache' \
    20 --exclude '__pycache__' \
    21 --exclude '*.pyc' \
    22 --exclude 'build' \
    23 --exclude '*.egg-info' \
    24 --exclude 'dist' \
    25 "$ROOT/" "$STAGE/$NAME/"
    Lines 15–25

    Copies the tree into <stage>/<name>/ with rsync -a, leaving out VCS data, virtualenvs, caches, build output and the dist directory. Excluding dist stops earlier archives from being packed into new ones. The top-level folder is named <name> so the zip unpacks into a single versioned directory.

    26​
    27rm -f "$DIST_DIR/$NAME.zip" "$DIST_DIR/$NAME.zip.sha256"
    Line 27

    Removes any previous zip and checksum for this version so a rebuild never leaves stale files.

    28(
    29 cd "$STAGE"
    30 zip -qr "$DIST_DIR/$NAME.zip" "$NAME"
    31)
    Lines 28–31

    Zips from inside the staging directory so archive paths start at <name>/ and do not include the temporary path. -q quiets the output and -r recurses.

    32(
    33 cd "$DIST_DIR"
    34 sha256sum "$NAME.zip" > "$NAME.zip.sha256"
    35)
    Lines 32–35

    Runs sha256sum from inside DIST_DIR, so the checksum file holds a bare filename and sha256sum -c works when the zip and checksum sit together. sha256sum is the GNU tool name, which is not present on every platform.

    37echo "$DIST_DIR/$NAME.zip"
    38echo "$DIST_DIR/$NAME.zip.sha256"
    Lines 37–38

    Prints the two output paths, one per line, so callers can read them from stdout.
