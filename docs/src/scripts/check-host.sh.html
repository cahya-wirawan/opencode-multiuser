    scripts/check-host.sh

    16 lines, 0 of 0 definitions explained, 5 line notes. View original

    In the guide: Installation, versioning and releases

    A read-only diagnostic that prints whether the current Linux user has what rootless Podman needs under systemd: a runtime directory, a user D-Bus socket, delegated cgroup controllers, and Podman's own cgroup/runtime settings. It makes no changes. install.sh runs similar preflight checks and aborts on failure, while this script only reports.

    1#!/usr/bin/env bash
    2set -euo pipefail
    3uid=$(id -u)
    4runtime=${XDG_RUNTIME_DIR:-/run/user/$uid}
    Line 4

    Uses XDG_RUNTIME_DIR when set, otherwise the conventional /run/user/<uid> path that a systemd user session provides.

    5controllers="/sys/fs/cgroup/user.slice/user-${uid}.slice/user@${uid}.service/cgroup.controllers"
    Line 5

    Path of the cgroup v2 file that lists the controllers systemd has delegated to this user's user@<uid>.service manager. Rootless Podman can only enforce CPU, memory and PID limits for controllers listed here.

    6​
    7echo "user: $(id -un) (uid=$uid)"
    8echo "runtime: $runtime"
    9[[ -d "$runtime" ]] && echo "runtime dir: OK" || echo "runtime dir: MISSING"
    10[[ -S "$runtime/bus" ]] && echo "user bus: OK" || echo "user bus: MISSING"
    Lines 9–10

    The [[ test ]] && echo OK || echo MISSING idiom is safe under set -e because the test sits in an &&/|| list. bus is tested with -S (is a socket), since systemctl --user needs that socket.

    11if [[ -r "$controllers" ]]; then
    12 echo "cgroup controllers: $(cat "$controllers")"
    13else
    14 echo "cgroup controllers: unavailable ($controllers)"
    15fi
    Lines 11–15

    The controllers file is printed if readable. If not, the script reports 'unavailable' with the path instead of failing, because the path may not exist on hosts without cgroup v2 or without a user manager.

    16podman info --format 'podman: cgroupVersion={{.Host.CgroupsVersion}} cgroupManager={{.Host.CgroupManager}} runtime={{.Host.OCIRuntime.Name}}' 2>/dev/null || true
    Line 16

    Asks Podman for cgroup version, cgroup manager and OCI runtime name. 2>/dev/null || true hides errors and keeps the exit status 0, so a missing or broken Podman does not abort the report.
