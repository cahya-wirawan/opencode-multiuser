    In the guide: Installation, versioning and releases

    Small CLI that shows, sets or bumps the project's Semantic Version. The only stored copy of the version is the __version__ = "X.Y.Z" line in app/version.py. This script edits it in place and accepts only strict MAJOR.MINOR.PATCH. package-release.sh calls its show command to name the release archive.

    20SEMVER_RE = re.compile(r"^(0|[1-9]\d*)\.(0|[1-9]\d*)\.(0|[1-9]\d*)$")
    21ASSIGNMENT_RE = re.compile(r'^__version__\s*=\s*"([^"]+)"\s*$', re.MULTILINE)
    Lines 18–21

    ROOT is found relative to this file, so the script works from any working directory. SEMVER_RE allows no leading zeros. ASSIGNMENT_RE uses re.MULTILINE so ^ and $ match at line boundaries and only a top-level __version__ = "..." line is matched.
