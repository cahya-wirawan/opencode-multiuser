    In the guide: Installation, versioning and releases

    Tests that keep the project's version number consistent: the package __version__ is a plain Semantic Version, it is shown in the login and registration pages, and the scripts/version.py show command prints the same value. It ties together app/__init__.py, app/ui.py and scripts/version.py.
