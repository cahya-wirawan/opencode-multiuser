    tests/test_gateway.py

    402 lines, 38 of 38 definitions explained, 26 line notes. View original

    In the guide: Authentication and roles, Starting a workspace runtime, The gateway proxy

    The main test module of the repository. Despite its name it covers much more than the gateway: Traefik URL and route cleanup, runtime helpers (host ports, per-workspace data directories, managed OpenCode provider policy, readiness polling), workspace deletion, the portal widget and HTML pages, role and OIDC provisioning, admin protections and OpenCode version validation. Most tests use monkeypatch to redirect settings values such as data_root to a pytest tmp_path, and in-memory SQLite for database-backed cases.
