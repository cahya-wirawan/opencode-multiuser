    In the guide: The gateway proxy

    Defines the small management widget that the gateway injects into OpenCode's own HTML pages. It holds the widget's CSS and JavaScript as string constants, a function that builds its markup, and a function that inserts that markup into an HTML document. The widget offers Dashboard, Stop workspace and Logout actions, and the script polls a status endpoint to send the user back to the dashboard when the workspace is no longer running.
