    In the guide: Admin console and engine updates

    Implements the admin-triggered OpenCode engine update. It builds a candidate workspace image with Podman, smoke-tests it, then retags it as the live workspace image and records the new version in the control-plane env file. Progress lives in a process-wide state object guarded by a lock, which the portal can poll.
