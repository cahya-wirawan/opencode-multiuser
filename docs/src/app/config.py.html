    app/config.py

    122 lines, 10 of 10 definitions explained, 10 line notes. View original

    In the guide: Architecture overview, Authentication and roles, Starting a workspace runtime

    Defines the Settings class, a pydantic-settings model holding all configuration for the control plane: domain and ports, database, JWT and cookies, authentication (local and OIDC), Podman workspace limits, Traefik and OpenCode provider policy. A module-level settings instance is created at import time, so other modules just import it.
