    In the guide: Architecture overview, Authentication and roles, Slots and workspace leases, The gateway proxy, Startup, reconciliation and idle reclamation, Admin console and engine updates

    app/main.py is the FastAPI application that acts as the control plane and gateway for OpenCode Multiuser. This part holds the workspace lease and slot bookkeeping helpers, the admin-safety helpers, the idle reaper, the startup lifespan (migrations, slot seeding, reconciliation), the app and session middleware setup, and the auth and login/registration routes. The rest of the file (parts 2 and 3) covers the dashboard, admin and workspace APIs, the portal widget endpoints, and the HTTP/WebSocket gateway proxy.
