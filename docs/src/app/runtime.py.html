    app/runtime.py

    290 lines, 23 of 23 definitions explained, 24 line notes. View original

    In the guide: Architecture overview, Slots and workspace leases, Starting a workspace runtime, Startup, reconciliation and idle reclamation

    Wraps the Podman CLI and the on-disk layout that make up a workspace runtime. It computes per-user/per-project data directories, stores the per-workspace Basic Auth secret, activity timestamp and stop reason as small files, starts a locked-down OpenCode container bound to a loopback port derived from its slot, and polls it until healthy. The gateway and the control plane in app/main.py (not shown here) call these helpers.
