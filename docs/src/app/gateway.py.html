    In the guide: Architecture overview, The gateway proxy

    The reverse proxy between the portal's public port and the per-workspace OpenCode containers. It picks the running workspace a request belongs to, swaps the user's portal session for the workspace's Basic Auth credentials, forwards HTTP (streaming) and WebSocket traffic to the container's loopback port, and injects the portal widget into HTML pages. It also records activity on every proxied exchange, which feeds idle reclamation elsewhere.
