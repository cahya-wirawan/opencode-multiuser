    In the guide: Authentication and roles, Admin console and engine updates

    Pydantic request and response models for the HTTP API: registration and login, token responses, workspace start and info, admin user updates and the OpenCode engine update request. Field constraints validate input at the API boundary.

    1from pydantic import BaseModel, Field
    2​
    3​
    4class RegisterRequest(BaseModel):
    5 username: str = Field(min_length=3, max_length=80, pattern=r"^[a-zA-Z0-9_.-]+$")
    6 password: str = Field(min_length=12, max_length=256)
    Lines 5–6

    Username and password limits are enforced by pydantic on input, so invalid requests are rejected before any handler logic runs.
