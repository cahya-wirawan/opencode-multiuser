    In the guide: Authentication and roles

    Authentication and authorization helpers for the control plane. It covers Argon2 password hashing, issuing and verifying HS256 JWT session tokens, resolving the current user from a bearer token or session cookie, and the first-user-becomes-admin rule. current_user and require_admin are FastAPI dependencies that protect routes.
