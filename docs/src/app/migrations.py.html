    app/migrations.py

    109 lines, 3 of 3 definitions explained, 12 line notes. View original

    In the guide: Slots and workspace leases, Startup, reconciliation and idle reclamation

    Idempotent startup migrations that bring older databases up to the current schema without a migration framework. They add the role and OIDC columns to users, drop an obsolete workspace constraint, and create the partial unique index that allows only one active workspace per user and project. It supports PostgreSQL (production) and SQLite and skips other dialects with a warning.
