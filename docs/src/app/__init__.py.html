    In the guide: Installation, versioning and releases

    Package marker for app that re-exports __version__ from app.version, so the version can be read as app.__version__. app/version.py remains the single place where the number is defined.

    1"""OpenCode Multiuser package."""
    2​
    3from .version import __version__
    Line 3

    Relative import of the version string from app/version.py; importing the app package therefore also imports that module.

    4​
    5__all__ = ["__version__"]
    Line 5

    __all__ limits from app import * to __version__ and marks the re-export as intentional.
