    Im Leitfaden: Installation, Versionierung und Releases

    Kleines CLI, das die Semantic Version des Projekts anzeigt, setzt oder erhöht. Die einzige gespeicherte Kopie der Version ist die Zeile __version__ = "X.Y.Z" in app/version.py. Dieses Skript bearbeitet sie direkt in der Datei und akzeptiert nur striktes MAJOR.MINOR.PATCH. package-release.sh ruft dessen Befehl show auf, um das Release-Archiv zu benennen.

    ROOT wird relativ zu dieser Datei bestimmt, sodass das Skript aus jedem Arbeitsverzeichnis funktioniert. SEMVER_RE erlaubt keine führenden Nullen. ASSIGNMENT_RE verwendet re.MULTILINE, damit ^ und $ an Zeilengrenzen greifen und nur eine Zeile __version__ = "..." auf oberster Ebene passt.
