    Im Leitfaden: Architekturübersicht, Authentifizierung und Rollen, Eine Workspace-Runtime starten

    Definiert die Klasse Settings, ein pydantic-settings-Modell, das die gesamte Konfiguration der Control Plane enthält: Domain und Ports, Datenbank, JWT und Cookies, Authentifizierung (lokal und OIDC), Podman-Workspace-Limits, Traefik und die OpenCode-Provider-Richtlinie. Eine settings-Instanz auf Modulebene wird beim Import erzeugt, sodass andere Module sie einfach importieren können.
