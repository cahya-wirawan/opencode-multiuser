    Im Leitfaden: Installation, Versionierung und Releases

    Paketmarkierung für app, die __version__ aus app.version erneut exportiert, sodass die Version als app.__version__ gelesen werden kann. app/version.py bleibt die einzige Stelle, an der die Nummer definiert wird.

    1"""OpenCode Multiuser package."""
    2​
    3from .version import __version__
    Zeile 3

    Relativer Import des Versionsstrings aus app/version.py; beim Import des Pakets app wird daher auch dieses Modul importiert.

    4​
    5__all__ = ["__version__"]
    Zeile 5

    __all__ beschränkt from app import * auf __version__ und kennzeichnet den Re-Export als beabsichtigt.
