    Dalam panduan: Instalasi, versioning, dan rilis

    Membangun arsip rilis opencode-multiuser-<version>.zip beserta file checksum .sha256 dari pohon repositori. Versi dibaca dari scripts/version.py show, dan arsip di-stage dengan rsync (mengecualikan .git, virtualenv, cache, dan output build) sebelum di-zip.

    1#!/usr/bin/env bash
    2set -euo pipefail
    3​
    4ROOT=$(cd "$(dirname "$0")/.." && pwd)
    5PYTHON_BIN=${PYTHON_BIN:-python3}
    6VERSION=$($PYTHON_BIN "$ROOT/scripts/version.py" show)
    7NAME="opencode-multiuser-${VERSION}"
    8DIST_DIR=${1:-"$ROOT/dist"}
    Baris 4–8

    Menentukan root repositori dari lokasi skrip, sehingga dapat dijalankan dari direktori kerja mana pun. PYTHON_BIN dapat di-override, dan argumen pertama menentukan direktori output (default <root>/dist). Versi diperoleh dengan menjalankan version.py show, sehingga nomor versi hanya memiliki satu sumber kebenaran.

    9STAGE=$(mktemp -d)
    10trap 'rm -rf "$STAGE"' EXIT
    Baris 9–10

    Men-stage salinan di direktori sementara yang dihapus oleh trap EXIT, bahkan jika langkah berikutnya gagal.

    11​
    12command -v rsync >/dev/null 2>&1 || { echo "ERROR: rsync is required" >&2; exit 1; }
    13command -v zip >/dev/null 2>&1 || { echo "ERROR: zip is required" >&2; exit 1; }
    Baris 12–13

    Memeriksa bahwa rsync dan zip tersedia sebelum melakukan pekerjaan apa pun dan keluar dengan pesan error yang jelas jika tidak ada.

    14​
    15mkdir -p "$DIST_DIR" "$STAGE/$NAME"
    16rsync -a \
    17 --exclude '.git' \
    18 --exclude '.venv' \
    19 --exclude '.pytest_cache' \
    20 --exclude '__pycache__' \
    21 --exclude '*.pyc' \
    22 --exclude 'build' \
    23 --exclude '*.egg-info' \
    24 --exclude 'dist' \
    25 "$ROOT/" "$STAGE/$NAME/"
    Baris 15–25

    Menyalin pohon ke <stage>/<name>/ dengan rsync -a, tanpa data VCS, virtualenv, cache, output build, dan direktori dist. Pengecualian dist mencegah arsip lama ikut dikemas ke dalam arsip baru. Folder tingkat atas diberi nama <name> agar zip terekstrak menjadi satu direktori berversi.

    26​
    27rm -f "$DIST_DIR/$NAME.zip" "$DIST_DIR/$NAME.zip.sha256"
    Baris 27

    Menghapus zip dan checksum sebelumnya untuk versi ini agar build ulang tidak meninggalkan file usang.

    28(
    29 cd "$STAGE"
    30 zip -qr "$DIST_DIR/$NAME.zip" "$NAME"
    31)
    Baris 28–31

    Men-zip dari dalam direktori staging sehingga path di dalam arsip diawali <name>/ dan tidak menyertakan path sementara. -q menenangkan output dan -r menelusuri secara rekursif.

    32(
    33 cd "$DIST_DIR"
    34 sha256sum "$NAME.zip" > "$NAME.zip.sha256"
    35)
    Baris 32–35

    Menjalankan sha256sum dari dalam DIST_DIR, sehingga file checksum hanya berisi nama file polos dan sha256sum -c bekerja ketika zip dan checksum berada bersama. sha256sum adalah nama tool GNU, yang tidak tersedia di setiap platform.

    36​
    37echo "$DIST_DIR/$NAME.zip"
    38echo "$DIST_DIR/$NAME.zip.sha256"
    Baris 37–38

    Mencetak kedua path output, satu per baris, sehingga pemanggil dapat membacanya dari stdout.
