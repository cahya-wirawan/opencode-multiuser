    scripts/check-host.sh

    16 baris, 0 dari 0 definisi dijelaskan, 5 catatan baris. Lihat versi asli

    Dalam panduan: Instalasi, versioning, dan rilis

    Diagnostik hanya-baca yang mencetak apakah pengguna Linux saat ini memiliki semua yang dibutuhkan Podman rootless di bawah systemd: direktori runtime, socket D-Bus pengguna, controller cgroup yang didelegasikan, serta pengaturan cgroup/runtime milik Podman sendiri. Skrip ini tidak mengubah apa pun. install.sh menjalankan pemeriksaan preflight yang serupa dan berhenti jika gagal, sedangkan skrip ini hanya melaporkan.

    1#!/usr/bin/env bash
    2set -euo pipefail
    3uid=$(id -u)
    4runtime=${XDG_RUNTIME_DIR:-/run/user/$uid}
    Baris 4

    Memakai XDG_RUNTIME_DIR bila diatur, jika tidak memakai path konvensional /run/user/<uid> yang disediakan oleh sesi pengguna systemd.

    5controllers="/sys/fs/cgroup/user.slice/user-${uid}.slice/user@${uid}.service/cgroup.controllers"
    Baris 5

    Path file cgroup v2 yang mencantumkan controller yang telah didelegasikan systemd ke manager user@<uid>.service milik pengguna ini. Podman rootless hanya dapat menerapkan batas CPU, memori, dan PID untuk controller yang tercantum di sini.

    6​
    7echo "user: $(id -un) (uid=$uid)"
    8echo "runtime: $runtime"
    9[[ -d "$runtime" ]] && echo "runtime dir: OK" || echo "runtime dir: MISSING"
    10[[ -S "$runtime/bus" ]] && echo "user bus: OK" || echo "user bus: MISSING"
    Baris 9–10

    Idiom [[ test ]] && echo OK || echo MISSING aman dipakai di bawah set -e karena pengujiannya berada dalam daftar &&/||. bus diuji dengan -S (apakah berupa socket), karena systemctl --user membutuhkan socket tersebut.

    11if [[ -r "$controllers" ]]; then
    12 echo "cgroup controllers: $(cat "$controllers")"
    13else
    14 echo "cgroup controllers: unavailable ($controllers)"
    15fi
    Baris 11–15

    File controller dicetak jika dapat dibaca. Jika tidak, skrip melaporkan 'unavailable' beserta path-nya alih-alih gagal, karena path tersebut mungkin tidak ada pada host tanpa cgroup v2 atau tanpa user manager.

    16podman info --format 'podman: cgroupVersion={{.Host.CgroupsVersion}} cgroupManager={{.Host.CgroupManager}} runtime={{.Host.OCIRuntime.Name}}' 2>/dev/null || true
    Baris 16

    Menanyakan kepada Podman versi cgroup, cgroup manager, dan nama runtime OCI. 2>/dev/null || true menyembunyikan error dan menjaga exit status tetap 0, sehingga Podman yang tidak ada atau rusak tidak membatalkan laporan.
