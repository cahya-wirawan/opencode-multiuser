    Dalam panduan: Instalasi, versioning, dan rilis

    Menyimpan versi aplikasi sebagai satu string __version__. Docstring-nya menyatakannya sebagai sumber kebenaran tunggal untuk nomor Semantic Versioning, dan app/__init__.py mengekspor ulang string ini.

    1"""Application version.
    2​
    3OpenCode Multiuser follows Semantic Versioning (MAJOR.MINOR.PATCH).
    4This module is the single source of truth for the application version.
    5Use ``python3 scripts/version.py`` to inspect or update it.
    6"""
    7​
    8__version__ = "0.11.2"
    Baris 8

    Literal versi itu sendiri, dalam bentuk MAJOR.MINOR.PATCH. Docstring menyatakan untuk memeriksa atau memperbaruinya dengan python3 scripts/version.py alih-alih menyuntingnya secara manual.
