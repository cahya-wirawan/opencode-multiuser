    Dalam panduan: Instalasi, versioning, dan rilis

    Penanda paket untuk app yang mengekspor ulang __version__ dari app.version, sehingga versi dapat dibaca sebagai app.__version__. app/version.py tetap menjadi satu-satunya tempat nomor versi didefinisikan.

    1"""OpenCode Multiuser package."""
    2​
    3from .version import __version__
    Baris 3

    Impor relatif untuk string versi dari app/version.py; mengimpor paket app dengan demikian juga mengimpor modul tersebut.

    4​
    5__all__ = ["__version__"]
    Baris 5

    __all__ membatasi from app import * hanya pada __version__ dan menandai bahwa ekspor ulang ini disengaja.
