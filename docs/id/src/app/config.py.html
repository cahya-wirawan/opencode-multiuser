    Dalam panduan: Gambaran arsitektur, Autentikasi dan role, Menjalankan runtime workspace

    Mendefinisikan kelas Settings, sebuah model pydantic-settings yang menyimpan seluruh konfigurasi control plane: domain dan port, database, JWT dan cookie, autentikasi (lokal dan OIDC), batasan workspace Podman, serta kebijakan provider Traefik dan OpenCode. Sebuah instance settings tingkat modul dibuat saat impor, sehingga modul lain cukup mengimpornya.
