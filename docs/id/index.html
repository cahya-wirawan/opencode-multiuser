    opencode-multiuser

    24 file, 3812 baris kode, 209 dari 209 definisi dijelaskan, 326 catatan baris.

    OpenCode Multiuser memungkinkan banyak orang memakai OpenCode melalui satu portal browser. Sebuah control plane FastAPI mengautentikasi pengguna (akun lokal atau OIDC generik), lalu menjalankan container Podman rootless yang sekali pakai dan terkunci, yang menjalankan opencode serve, untuk setiap proyek yang dibuka pengguna. File proyek dan state OpenCode berada di direktori per-pengguna pada host, sehingga container dapat dihancurkan dan dibuat ulang tanpa kehilangan pekerjaan. Kapasitas berupa kumpulan slot bernomor yang tetap (MAX_SLOTS), dan container dibuat sesuai permintaan serta dihapus saat stop, logout, atau idle timeout.

    Aplikasi FastAPI yang sama juga berperan sebagai gateway. Traefik meneruskan satu hostname publik ke aplikasi ini. Request yang bukan rute portal jatuh ke proxy catch-all di app/gateway.py, yang menemukan workspace pengguna yang sedang berjalan, menukar sesi portal dengan kredensial Basic Auth privat milik container tersebut, dan meneruskan lalu lintas HTTP dan WebSocket ke port khusus loopback yang diturunkan dari slot. app/runtime.py adalah satu-satunya kode yang berbicara dengan Podman, app/models.py dan app/migrations.py mendefinisikan state PostgreSQL, dan sebuah reaper di latar belakang merekonsiliasi lease di database dengan container yang benar-benar ada.

    4. Menjalankan runtime workspaceLihat apa yang terjadi saat sebuah container dibuat: tata letak di disk, flag keamanan, kebijakan provider terkelola, dan penantian kesiapan.
    5. Proxy gatewayIkuti satu request browser melalui pemilihan workspace, penukaran kredensial, streaming, relay WebSocket, dan injeksi widget.
    6. Startup, rekonsiliasi, dan reklamasi idlePahami bagaimana aplikasi menyiapkan database saat startup dan menjaga lease di database tetap selaras dengan container yang sebenarnya dari waktu ke waktu.

    Konsep yang akan Anda temui

    Slot dan lease workspace
    Satu baris Slot adalah satu unit kapasitas dan satu baris Workspace menahan sebuah slot selama workspace sedang dimulai, berjalan, atau dihentikan. Indeks unik parsial hanya mengizinkan satu workspace aktif per pengguna dan proyek.
    Runtime sekali pakai, state persisten
    Setiap container workspace dibuat baru dan dihapus saat stop, sementara direktori data workspace dan OpenCode-nya tetap disimpan di bawah data root. Secret per-workspace, timestamp aktivitas, dan alasan berhenti adalah file-file kecil di direktori yang sama.
    Proxying gateway
    Browser tidak pernah berbicara langsung dengan container workspace. Gateway memeriksa bahwa workspace yang dipilih sedang berjalan dan dimiliki pengguna, membuang kredensial portal, menyuntikkan Basic Auth milik container, dan menambahkan widget Portal ke halaman HTML.
    Rekonsiliasi dan reklamasi idle
    Database bisa menyimpang dari apa yang benar-benar dijalankan Podman. Saat startup dan pada setiap tick reaper, lease yang usang didaur ulang dan workspace yang idle melewati timeout dihentikan, dengan alasan berhenti dicatat agar gateway dapat menjelaskannya kepada pengguna.
    Kebijakan provider terpusat
    Daftar provider OpenCode yang diaktifkan dan dinonaktifkan yang dipilih administrator ditulis ke file konfigurasi terkelola dan di-mount read-only ke setiap workspace, sehingga pengguna tidak dapat menimpanya.
    Satu sumber versi
    app/version.py menyimpan satu-satunya salinan nomor versi. UI, metadata API, installer, dan pengemasan rilis semuanya membacanya, dan scripts/version.py menyuntingnya.

    • app/config.py 122 baris, 10/10 definisi

      Mendefinisikan kelas Settings, sebuah model pydantic-settings yang menyimpan seluruh konfigurasi control plane: domain dan port, database, JWT dan cookie, autentikasi (lokal dan OIDC), batasan workspace Podman, serta kebijakan provider Traefik dan OpenCode. Sebuah instance settings tingkat modul dibuat saat impor, sehingga modul lain cukup mengimpornya.

    • app/db.py 23 baris, 2/2 definisi

      Menyiapkan lapisan database SQLAlchemy: Base deklaratif untuk model, engine yang dibangun dari settings.database_url, factory SessionLocal, dan dependency sesi get_db.

    • app/gateway.py 290 baris, 14/14 definisi

      Reverse proxy antara port publik portal dan container OpenCode per-workspace. Proxy ini memilih workspace berjalan yang menjadi tujuan sebuah request, menukar sesi portal pengguna dengan kredensial Basic Auth milik workspace, meneruskan lalu lintas HTTP (streaming) dan WebSocket ke port loopback container, serta menyisipkan widget portal ke halaman HTML. Proxy ini juga mencatat aktivitas pada setiap pertukaran yang diproksikan, yang dipakai untuk reklamasi workspace idle di tempat lain.

    • app/main.py 989 baris, 58/58 definisi

      app/main.py adalah aplikasi FastAPI yang berperan sebagai control plane dan gateway untuk OpenCode Multiuser. Bagian ini memuat helper pembukuan lease dan slot workspace, helper keamanan admin, idle reaper, lifespan saat startup (migrasi, seeding slot, rekonsiliasi), penyiapan aplikasi dan middleware sesi, serta route autentikasi dan login/registrasi. Sisa file (bagian 2 dan 3) mencakup dashboard, API admin dan workspace, endpoint widget portal, dan proxy gateway HTTP/WebSocket.

    • app/migrations.py 109 baris, 3/3 definisi

      Migrasi startup yang idempoten yang membawa database lama ke skema saat ini tanpa framework migrasi. Migrasi ini menambahkan kolom role dan OIDC ke users, menghapus constraint workspace yang sudah usang, dan membuat partial unique index yang hanya mengizinkan satu workspace aktif per pengguna dan proyek. Mendukung PostgreSQL (produksi) dan SQLite, dan melewati dialek lain dengan peringatan.

    • app/models.py 83 baris, 6/6 definisi

      Model ORM SQLAlchemy untuk database portal: pengguna, kumpulan slot workspace, dan workspace. File ini juga mendefinisikan enum status dan role. Partial unique index yang dideklarasikan di sini mengodekan dua invarian: satu akun per identitas OIDC, dan satu workspace aktif per pengguna dan proyek.

    • app/oidc.py 131 baris, 6/6 definisi

      Dukungan OpenID Connect generik yang dibangun di atas Authlib. File ini mendaftarkan satu client OIDC dari settings dan memetakan claim dari provider ke baris User lokal, serta membuat pengguna saat login pertama jika auto-provisioning diaktifkan. Jika Authlib tidak terpasang, modul tetap dapat di-import dan request OIDC gagal dengan HTTP 503, sehingga deployment yang hanya memakai autentikasi lokal tetap berjalan.

    • app/opencode_update.py 234 baris, 14/14 definisi

      Mengimplementasikan pembaruan engine OpenCode yang dipicu oleh admin. File ini membangun image workspace kandidat dengan Podman, melakukan smoke test, lalu memberi tag ulang sebagai image workspace yang aktif dan mencatat versi baru di file env control-plane. Progres disimpan dalam objek state tingkat proses yang dijaga oleh lock, yang dapat di-poll oleh portal.

    • app/portal.py 111 baris, 2/2 definisi

      Mendefinisikan widget manajemen kecil yang disuntikkan gateway ke halaman HTML milik OpenCode sendiri. File ini menyimpan CSS dan JavaScript widget sebagai konstanta string, sebuah fungsi yang membangun markup-nya, dan sebuah fungsi yang menyisipkan markup itu ke dokumen HTML. Widget menawarkan aksi Dashboard, Stop workspace, dan Logout, dan skripnya melakukan polling ke endpoint status untuk mengembalikan pengguna ke dashboard ketika workspace tidak lagi berjalan.

    • app/runtime.py 290 baris, 23/23 definisi

      Membungkus CLI Podman dan tata letak di disk yang membentuk runtime sebuah workspace. File ini menghitung direktori data per pengguna/per proyek, menyimpan secret Basic Auth per workspace, timestamp aktivitas, dan alasan berhenti sebagai file kecil, memulai container OpenCode yang dikunci ketat dan terikat ke port loopback yang diturunkan dari slot-nya, lalu melakukan polling sampai container sehat. Gateway dan control plane di app/main.py (tidak ditampilkan di sini) memanggil helper-helper ini.

    • app/schemas.py 46 baris, 9/9 definisi

      Model request dan response Pydantic untuk HTTP API: registrasi dan login, response token, start dan info workspace, pembaruan pengguna oleh admin, dan request pembaruan engine OpenCode. Constraint field memvalidasi input di batas API.

    • app/security.py 83 baris, 7/7 definisi

      Helper autentikasi dan otorisasi untuk control plane. Mencakup hashing password Argon2, penerbitan dan verifikasi token sesi JWT HS256, penentuan pengguna saat ini dari bearer token atau cookie sesi, dan aturan pengguna pertama menjadi admin. current_user dan require_admin adalah dependency FastAPI yang melindungi route.

    • app/traefik.py 14 baris, 2/2 definisi

      Helper kecil untuk sisi Traefik dari platform: membangun URL publik yang dipakai untuk membuka workspace dan menghapus file route Traefik per-workspace sisa dari desain lama.

    • app/ui.py 268 baris, 6/6 definisi

      HTML yang dirender di server untuk halaman milik portal sendiri: login, registrasi, dashboard workspace, konsol pengguna admin, dan konsol sistem admin. Setiap halaman adalah satu f-string Python dengan JavaScript inline, dan semuanya berbagi stylesheet APP_CSS dan ikon SVG inline dari _icon. Halaman-halaman ini adalah shell statis. Setelah dimuat, halaman mengambil data dari endpoint JSON portal (misalnya /workspaces, /api/admin/users).

    • scripts/check-host.sh 16 baris

      Diagnostik hanya-baca yang mencetak apakah pengguna Linux saat ini memiliki semua yang dibutuhkan Podman rootless di bawah systemd: direktori runtime, socket D-Bus pengguna, controller cgroup yang didelegasikan, serta pengaturan cgroup/runtime milik Podman sendiri. Skrip ini tidak mengubah apa pun. install.sh menjalankan pemeriksaan preflight yang serupa dan berhenti jika gagal, sedangkan skrip ini hanya melaporkan.

    • scripts/install.sh 421 baris

      Installer dan upgrader untuk host dengan satu akun pengguna. Dijalankan dari pohon rilis yang sudah diekstrak, skrip ini melakukan preflight terhadap Python, sesi pengguna systemd, dan delegasi cgroup. Setelah itu skrip menyalin aplikasi ke ~/opt/opencode-multiuser, menulis atau memigrasikan control-plane.env, me-render file Quadlet dan Traefik, membangun venv Python dan image workspace, lalu menjalankan service. Skrip ini dirancang untuk dijalankan ulang saat upgrade: pengaturan yang sudah tersimpan di control-plane.env dipertahankan kecuali variabel yang sesuai diatur secara eksplisit di environment.

    • scripts/package-release.sh 38 baris

      Membangun arsip rilis opencode-multiuser-<version>.zip beserta file checksum .sha256 dari pohon repositori. Versi dibaca dari scripts/version.py show, dan arsip di-stage dengan rsync (mengecualikan .git, virtualenv, cache, dan output build) sebelum di-zip.

    • scripts/reset-orphans.sh 4 baris

      Helper pembersihan yang menghapus paksa container workspace OpenCode yang tertinggal dari Podman. Filter nama sengaja dibuat ketat, sehingga hanya container workspace yang dialokasikan secara dinamis yang disentuh dan service tetap seperti PostgreSQL dan Traefik tidak terpengaruh.

    • scripts/version.py 83 baris, 5/5 definisi

      CLI kecil yang menampilkan, mengatur, atau menaikkan Semantic Version proyek. Satu-satunya salinan versi yang tersimpan adalah baris __version__ = "X.Y.Z" di app/version.py. Skrip ini menyuntingnya di tempat dan hanya menerima format ketat MAJOR.MINOR.PATCH. package-release.sh memanggil perintah show-nya untuk menamai arsip rilis.

    • tests/test_gateway.py 402 baris, 38/38 definisi

      Modul pengujian utama repositori. Meskipun bernama gateway, cakupannya jauh lebih luas: URL Traefik dan pembersihan rute, helper runtime (port host, direktori data per-workspace, kebijakan provider OpenCode terkelola, polling kesiapan), penghapusan workspace, widget dan halaman HTML portal, provisioning role dan OIDC, proteksi admin, serta validasi versi OpenCode. Sebagian besar tes memakai monkeypatch untuk mengalihkan nilai settings seperti data_root ke tmp_path pytest, dan SQLite in-memory untuk kasus yang berbasis database.

    • tests/test_traefik.py 10 baris, 1/1 definisi

      Unit test untuk app.traefik.workspace_open_url, helper yang membangun URL browser yang dipakai untuk membuka workspace melalui satu host portal. Tes ini menetapkan bagaimana URL control-plane yang dikonfigurasi digabungkan dengan id workspace.

    • tests/test_version.py 32 baris, 3/3 definisi

      Tes yang menjaga nomor versi proyek tetap konsisten: __version__ paket adalah Semantic Version biasa, ditampilkan di halaman login dan registrasi, dan perintah scripts/version.py show mencetak nilai yang sama. Tes ini menghubungkan app/__init__.py, app/ui.py, dan scripts/version.py.
